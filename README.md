# Apex Learning - Professional Tutoring Platform

Apex Learning is a modern, high-performance landing page for an educational tutoring service. It is designed to showcase academic services, highlight expert tutors, and provide a seamless booking experience for students seeking to unlock their full potential.

### 🚀 Live Preview

The site features a responsive design optimized for mobile, tablet, and desktop viewing, ensuring a professional experience across all devices.

### ✨ Features

- Hero Section: Engaging call-to-action with key statistics.

- Service Highlights: Categorized tutoring for Math, Science, English, and Test Prep.

- Expert Tutors Section: Information about certified professionals.

- Responsive Navigation: Clean, accessible menu with mobile-friendly interactions.

- Modern UI: Built with a "less is more" aesthetic using professional typography and spacing.

### 🛠️ Tech Stack

This project was built using the following modern web technologies:

- React 19: For building a fast, component-based user interface.

- Vite: The next-generation frontend tooling for an ultra-fast development experience.

- Tailwind CSS v4: A utility-first CSS framework for modern, performant styling.

- Lucide React: A clean and consistent icon library.

- Google Fonts: Utilizing Noto Sans for high readability.

### 📦 Installation & Local Setup

To run this project on your local machine, follow these steps:

- Clone the repository

- Install dependencies

- npm install

- Run the development server:
npm run dev
